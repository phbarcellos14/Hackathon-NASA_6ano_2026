# Hackathon NASA Space Apps 2026 - Space Doctor (ASLS)

Aplicacao web estatica (HTML + JS + Three.js local). Nao precisa de instalacao.

## Como rodar
- Abra `index.html` no navegador (Chrome/Edge), ou
- Sirva a pasta: `python -m http.server 8000` e acesse http://localhost:8000
- Tambem funciona no GitHub Pages (Settings > Pages > branch main, pasta root).

Arquivos principais: `index.html`, `spacedoc.html`, modulos `*3d.js`, `plan.js`, `narr.js`, pastas `narr/` (audios) e `vendor/` (three.min.js).
